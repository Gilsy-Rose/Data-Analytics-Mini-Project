# Data-Analytics-Mini-Project
Student-Retention-Analysis
**Project Overview
*This project is part of the Data Analytics Mini Project. It focuses on analyzing student retention and academic performance using Microsoft Excel and Power BI.
Project Objectives
Clean and preprocess raw data using Excel.
Remove duplicate records and handle missing values.
Standardize data formats.
Perform filtering, sorting, and Pivot Table analysis.
Create interactive dashboards using Power BI.
Analyze student academic performance and dropout patterns.


Source: Kaggle

Dataset URL:
https://www.kaggle.com/datasets/razanihababdellatif/student-retention-and-academic-performance-data
